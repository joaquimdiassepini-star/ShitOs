# Sh!tOS

Sh!tOS is an experimental operating system project developed in Python. The project started as a custom terminal and is being developed step by step toward a complete operating system.

# About

Sh!tOS is a personal project focused on learning programming, system development, and operating system concepts by building the components from scratch.

The project was originally called JoaquimOS and was later renamed to Sh!tOS.

# Current Features

## Custom Terminal

The project currently includes a custom terminal written in Python.

The terminal is capable of:

- Starting the system
- Running a continuous command loop
- Reading user commands
- Separating commands from their arguments
- Processing command arguments
- Recognizing available commands
- Detecting unknown commands
- Providing a structure for adding new commands

The command system currently uses Python's `match` statement to organize command processing.

# File System

Work has also started on the file system functionality.

The project includes the beginning of functions for manipulating files, such as copying files between locations.

This system is still under development.
