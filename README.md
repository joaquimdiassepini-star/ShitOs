# Sh!tOS

![Python](https://img.shields.io/badge/Python-3.x-blue)
![Status](https://img.shields.io/badge/Status-In%20Development-orange)

Sh!tOS is an experimental operating system project developed in Python. The project started with a custom terminal and is being developed step by step toward a complete operating system.

# About

Sh!tOS is a personal project focused on learning programming, system development, and operating system concepts by building the system step by step.

The project was originally called JoaquimOS and was later renamed to Sh!tOS.

The current project is focused on creating the foundation of the operating system, including a custom terminal, command processing, and an experimental file system.

# Current Features

## Custom Terminal

Sh!tOS currently includes a custom terminal developed in Python.

The terminal is responsible for reading commands entered by the user and processing them.

Current functionality includes:

- Terminal initialization
- Command input
- Command processing
- Command arguments
- Command recognition
- Unknown command detection
- Command structure using Python
- A foundation for adding new commands

# File System

The project also contains an experimental file system.

Current files related to the file system include:

filesystem.py
filesystem.json

The file system is still under development and will eventually be expanded with more functionality for managing files and directories.

# File Description
# main.py

Main entry point of the Sh!tOS project.

It is responsible for starting the system and connecting the main components.

# Kernel.py

Contains the experimental kernel-related structure of the project.

This file will become more important as the project evolves toward a more complete operating system architecture.

# CMD.py

Contains the custom command system used by the Sh!tOS terminal.

It is responsible for processing and organizing terminal commands.

# filesystem.py

Contains the experimental file system functionality.

# filesystem.json

Stores data used by the experimental file system.

# README.md

Project documentation.

# How to Run

Make sure Python is installed on your computer.

Clone the repository:
 git clone https://github.com/joaquimdiassepini-star/ShitOS.git
 
Enter the project directory:
 cd ShitOS
 
Run the main program:
 python main.py
